Pockr

Docker on Android

Run Docker containers on a non-rooted Android device. Pull images, start containers, tail logs — all from a native Flutter UI backed by a Docker daemon in an Alpine VM.

GitHub → Download APK

Features

🐳
Pull & run any image
Full Docker daemon running inside the Alpine VM
📋
Real-time container logs
Stream logs from any running container directly in the app
🖥️
VM terminal
Shell access directly into the Alpine VM host
⚙️
Configurable resources
1–4 vCPU cores, 512 MB–4 GB RAM, adjustable per session
🔓
No root required
QEMU user-mode networking (SLIRP) as a regular app
🔐
Token auth
UUID token injected via QEMU kernel cmdline, read from /proc/cmdline
