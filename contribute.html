Volunteer & contribute

All AI2TH projects are open source. If you want to contribute — fix a bug, add a feature, improve docs, or test on hardware — you're welcome to jump in.

1
Pick a project
Browse the repos and find something that interests you.
2
Open an issue or pick an existing one
Comment on the issue to let others know you're working on it.
3
Fork, build, and open a PR
We review all pull requests and give feedback promptly.
