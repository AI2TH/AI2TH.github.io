Linxr

Linux, containers, k3s & PBX on Android

A full Alpine Linux environment running inside QEMU on Android. Real bash shell, SSH, containers, k3s Kubernetes, Asterisk PBX and a Linux desktop — on any arm64 phone, without root. Pockr, Zyvr and Kubxr are now merged into Linxr.

GitHub → Download APK Google Play (closed testing)

Features

🐧
Alpine 3.20 and kernel 6.18-virt
Real Linux kernel 6.18-virt with Alpine Linux 3.20, OpenRC init, OpenSSH, sudo, and apk package manager
⚙️
QEMU virtualization engine
QEMU arm64 on a Cortex-A76 model with multi-threaded TCG across up to 4 vCPUs; virtio-net, -blk, -rng and -9p devices
📜
System and VM log console
Live streaming kernel serial logs (dmesg, init, sshd) directly on Home Screen
🐳
FastTrack OCI and Docker
Daemonless podman/crun containers (idle CPU under 1%) or Docker; start, restart, inspect, export and import. Merged from Pockr
🖥️
Linux desktop GUI
Openbox or XFCE4 desktop for X11, GTK and Qt apps, viewed in-app through noVNC (new in v3.4)
☸️
k3s Kubernetes
k3s with cgroup2 and fast TLS (~15 ms handshakes); manage it with Vizxr. Merged from Kubxr
📞
Asterisk PBX
Asterisk 20 VoIP PBX as a container or native service from the Marketplace. Merged from Zyvr
🔌
Port forwarding
Open VM web apps in Chrome on localhost; custom mappings, loopback-only by default with an opt-in LAN toggle
📡
Built-in SSH terminal
SSH terminal tab with auto-reconnect and UTF-8 multi-byte encoding
💾
Virtio-9P storage sharing
Direct POSIX file path sharing between Android host and guest Linux VM

Start with the Marketplace

Recipes install a full stack in one tap, either as a Docker container or as a native Alpine service. Community recipes live in AI2TH/linxr-marketplace.

1 · Use

Install a recipe

  1. Start the VM on the Home tab.
  2. Open Marketplace and tap ↻ Refresh to sync community recipes.
  3. Filter by Docker or Native, pick a recipe, tap Deploy.
  4. Open the app in Chrome at http://localhost:<port>, for example 8080.
2 · Make your own

Build or import a recipe

  1. In Marketplace, open the custom recipe builder.
  2. Choose docker (image and ports) or script (an apk install script).
  3. Save it, or import a recipe JSON someone shared with you.
  4. Export your recipe as JSON to share it.
3 · Share

Publish to everyone

  1. Fork linxr-marketplace.
  2. Add your entry to recipes.json.
  3. Check it with node validate.js, then open a pull request.
  4. Once merged, every Linxr user gets it on the next Refresh.

How it works

One APK carries a whole Linux VM. QEMU gives the virtual machine, Alpine the system, the app the controls.

Flutter UI (Dart)
Home, Terminal, Containers, Marketplace, Desktop, Files, Settings
↓
Kotlin VmManager
Starts libqemu.so and keeps it alive as a foreground service
↓
QEMU (libqemu.so)
Shipped inside the APK; runs as a normal app process, no root
↓
Alpine Linux VM
Kernel 6.18-virt, OpenRC, SSH, apk; disk image grows on boot
↓
Your workloads
Containers · k3s · Asterisk PBX · Linux desktop · bash
