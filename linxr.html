Linxr

Alpine Linux Shell on Android

A full Alpine Linux environment running inside QEMU on Android. Real bash shell, SSH access, persistent storage — on any arm64 phone with zero root.

GitHub → Download APK

Features

📜
System & VM Log Console
Live streaming kernel serial logs (dmesg, init, sshd) directly on Home Screen
🐳
Docker & Container Manager
Integrated Pockr container dashboard to deploy, log, and manage Docker containers
⚡
15-Second Boot Speed
Optimized SSH probe locks and Virtio-9P passthrough for instant bootup
📡
Built-in SSH terminal
SSH terminal tab with auto-reconnect and UTF-8 multi-byte encoding
💾
Virtio-9P Storage Sharing
Direct POSIX file path sharing between Android host and guest Linux VM
🔓
No root required
Full QEMU virtual machine environment running under standard app sandbox
