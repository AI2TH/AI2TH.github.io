Linxr

Alpine Linux Shell on Android

A full Alpine Linux environment running inside QEMU on Android. Real bash shell, SSH access, persistent storage — on any arm64 phone with zero root.

GitHub → Download APK

Features

🖥️
Full Linux shell
Alpine Linux 3.19 with OpenRC init, OpenSSH, sudo, bash
📡
Built-in SSH terminal
SSH terminal tab with auto-reconnect, no client needed
🔌
External SSH access
Connect from any SSH client on the same device or network
🔓
No root required
QEMU runs as a normal Android app process
💾
Persistent storage
Writable QCOW2 overlay preserves changes across reboots
🌐
Internet access
SLIRP networking gives the VM full outbound internet
