Vizxr

Kubernetes IDE for Android

Kubernetes management in your pocket. Vizxr is a pure UI layer: it runs no control plane of its own and connects to the clusters you already have, from Linxr’s local k3s to AKS, GKE and EKS.

Download APK → GitHub

Features

🔎
Resource inspector
Lens-style slide-over dock with overview, containers and pod specs, live events and manifest YAML
📈
Live metrics
Cluster CPU and memory sparklines with utilization pills for pods and nodes
🧩
CRD explorer
Discover CustomResourceDefinitions and drill into live custom resources
⛵
Helm hub
Browse repositories, inspect release revisions and values, roll back or uninstall in one tap
📜
Log streamer
Tail logs from several containers in real time
🖥️
Pod exec
Integrated terminal for kubectl exec straight into containers
📝
YAML editor
View and change resource manifests with syntax highlighting
🔀
Multi-cluster
Switch contexts from the cluster drawer; import kubeconfig for cloud clusters

How it works

Vizxr runs no control plane of its own. It is a client for the clusters you already have.

Flutter UI (Dart)
Explorer, inspector, logs, exec, YAML, Helm
↓
Context manager
Local and cloud clusters from imported kubeconfig
↓
Kubernetes client (Dart)
Talks to the API server over HTTPS / TLS
↓
Your cluster
Linxr k3s on localhost:6443 · AKS · GKE · EKS

Use it with Linxr

A complete Kubernetes lab on one phone, no cloud account needed.

1
Install k3s in Linxr
Open the Linxr Marketplace and deploy the k3s recipe.
2
Connect Vizxr
Vizxr reaches the local API server on localhost:6443.
3
Operate the cluster
Inspect workloads, stream logs, exec into pods and apply YAML from your phone.
