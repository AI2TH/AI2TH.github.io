cryptship

Software delivery

Ship encrypted, license-gated application code inside Docker images. The image is ciphertext; a small loader runs your app only with a valid license.

  • AES-256-GCM payloads, Ed25519 licenses
  • Air-gapped, on-prem and cloud modes
  • Instant revocation via license server
  • Hardening and per-license watermarks
v0.1.0 · Go · GPLv3

How Linxr works

Linxr carries a whole Linux virtual machine inside its APK: QEMU provides the VM, Alpine Linux the system, and the app the controls.

Flutter UI (Dart)
Home, Terminal, Containers, Marketplace, Desktop, Files, Settings
↓
Kotlin VmManager
Starts libqemu.so and keeps it alive as a foreground service
↓
QEMU (libqemu.so)
Shipped inside the APK; runs as a normal app process, no root
↓
Alpine Linux VM
Kernel 6.18-virt, OpenRC, SSH, apk; disk image grows on boot
↓
Your workloads
Containers · k3s · Asterisk PBX · Linux desktop · bash
