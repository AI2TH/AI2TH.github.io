Zyvr

Asterisk PBX on Android

Zero-carrier Your Voice Router. A full Asterisk 20 PBX running on your phone. Manage SIP extensions, monitor live calls, send SIP text messages, and route calls — carrier-independent.

GitHub → Download APK

Features

📞
Asterisk 20 + PJSIP
Full PBX engine with modern PJSIP channel driver
👤
SIP extension management
Create, delete, and list SIP extensions from the app UI
📊
Live call monitor
View active calls and hang up channels in real time
🌐
WebRTC / SIP.js
WSS on port 8089, DTLS/SRTP, self-signed cert on first boot
💾
Persistent config
user.qcow2 overlay preserves SIP extensions and voicemail across reboots
💬
SIP text messaging
Send and receive SIP MESSAGE between extensions via AMI — with delivery status
🔓
No root required
Runs entirely in user space via QEMU SLIRP networking
